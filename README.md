# ПАРАЛЛЕЛЬ

Интерактивный образовательный тренажёр по геометрии для учащихся 7 класса. Помогает разобраться в свойствах параллельных прямых, признаках параллельности и углах, образованных секущей (соответственные, накрест лежащие, односторонние).

Разработчики: **Mironov & Kondratiev**

---

## Возможности

- **Интерактивная теория**: 6 тематических разделов с понятными объяснениями и динамической шпаргалкой по парам углов на SVG-схеме.
- **Режим тренировки**: 8 практических задач с моментальной обратной связью, подробным объяснением и ссылкой на использованную теорему.
- **Итоговый экзамен**: 10 контрольных вопросов с навигацией по заданиям, подтверждением отправки, порогом успешной сдачи 70% и разбором ошибок.
- **Генерация сертификата**: Персональный сертификат об окончании с печатью в формате 1 страницы A4 или сохранением в PDF.
- **Минималистичный дизайн**: Чистый визуальный стиль, вдохновлённый эстетикой Mobbin (#FFFFFF и #12131A), типографическая анимация вариативного заголовка «ПАРАЛЛЕЛЬ», поддержка `prefers-reduced-motion` и доступности по WCAG (клавиатурная навигация, skip-link, focus-ring, aria-live).
- **Автономность**: Без внешних бэкендов, аналитики и сторонних библиотек маршрутизации (собственный hash-router). Локальное хранение прогресса в localStorage с резервным хранением в оперативной памяти.

## Запуск и сборка

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

Локальный сервер запустится по адресу [http://localhost:3000](http://localhost:3000).

### Сборка для публикации (Production)

```bash
npm run build
```

Готовые статические файлы будут скомпилированы в папку `dist/`. Проект оптимизирован для развёртывания на GitHub Pages с относительными путями (`base: './'`).

### Предпросмотр сборки

```bash
npm run preview
```
